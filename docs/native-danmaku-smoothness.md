# 原生弹幕流畅度优化验收（0.11.1）

本次仅修改原生弹幕 Lua、相关测试和版本／文档。影片传输、IINA 启动参数、音频解码及原始 ASS 字幕链路没有改动；未重对齐或生成媒体副本。

## 实现

- 独立单调时钟在量化的影片 PTS 之间平滑推进，以源时间校准，预测上限为一个源视频帧；拖动、倍速、暂停和缓冲会重新同步。无缓存暂停信号的停滞也不会无限外推。
- 根据显示刷新率采用绝对期限调度，默认 60、上限 120 次／秒；暂停、缓冲和关闭弹幕时停止动画定时器。避免周期回调耗时不断累积到下一周期。
- 首次加载时缓存转义文本、颜色和字符长度；活动弹幕缓存样式与布局，过期即释放。设置调整不再重复读取、解析、排序整份弹幕；内容不变时不重新提交 OSD。
- 保留颜色、滚动、顶部／底部、字幕避让、估算筛选和独立偏移。用户字号保持原值，仍可通过网页实时调整。

## 真实 IINA 对照

IINA 1.4.4 / mpv 0.38.0；60 Hz 显示环境；640×360、24 fps、DTS 六声道合成片，32 条滚动弹幕和顶部／底部弹幕，原始双行样式 ASS。新旧交替各三轮，每轮预热约 0.8 秒、测量约 4 秒；相同原片、设置及诊断包装。所有窗口静音，按各自会话控制并关闭。

| 指标（三轮中位） | 旧版 | 新版 |
| --- | ---: | ---: |
| OSD 滚动位置更新／秒 | 23.26 | 59.98 |
| 更新间隔 P95 | 72.50 ms | 22.37 ms |
| IINA CPU 秒／墙钟秒 | 0.135 | 0.167 |

上述为 Lua／OSD 提交采样，**不是物理屏幕呈现 FPS，也不是整部 4K 影片的长期性能结论**。带诊断采样时，CPU 增加约 3.2 个单核百分点，换取更密的动画更新；不将本次改动称为降低总 CPU。没有改变影片的 24 fps 或开启视频插帧。

真实 IINA 验证：暂停后 OSD 提交停止；调小字号时不重读弹幕文件；字幕与弹幕偏移互不影响；倍速、拖动、暂停恢复正常。每轮原始 ASS 保持选中，DTS 仍解码为六声道，当前设备输出双声道 PCM。120 Hz 仅通过确定性测试，未进行物理 120 Hz 屏幕验收。

## 本片

使用原 MKV、原始中文 ASS 和现有 7,981 条映射弹幕，在独立数据库和静音窗口短时验证；没有截图或展示未来片段。

- 影片、外部 ASS、弹幕三路共同就绪；新平滑时钟开始插值，弹幕文件只读取一次。
- 源音轨 DTS-HD MA 5.1(side)、48 kHz，解码六声道；实际播放器输出双声道 PCM。没有应用层 AAC 或视频编码。
- 原始 ASS 保持选中，1,071 条对白，文件字节不变；原片身份、大小、mtime、ctime 保持不变。
- 原始外挂的听感同步、主观流畅度、物理 5.1 输出和长时间观看仍需正常观看确认；不将“加载成功”当作这些项目通过。

## 回归与发布

234 项 Python 测试通过（含新增动画测试），5 组前端回归通过；1 项既有 Starlette/httpx 弃用提示。

确定性测试覆盖 24/30 fps、60/120 Hz 调度、1/1.5/2 倍速，动画时间误差不超过一个源帧；另覆盖暂停、缓冲、无信号停滞、跳转、弹幕开关、颜色、转义、字号与不透明度、缓存复用。

发布前备份源码及 SQLite，校验新旧文件摘要。只结束本工具拥有的原生会话并保存进度；服务更新后恢复原片、原始字幕和弹幕，保持暂停。不会写入 IINA 全局偏好或修改用户影片。

机器记录、诊断基准和测试日志保存在本地私有实验归档，不随仓库发布。基准包含诊断包装，正常播放不加载该包装。

## 后续更正（0.11.2）

本报告中的约 60 次／秒是脚本提交率。后续本片大窗口复测确认，0.11.1 的实际 OSD 绘制仍约 24 次／秒，所以上一轮验收不足以证明观感流畅。0.11.2 已针对显示同步修复，并以真实渲染日志交叉验证，详见 [修复与本片对照](native-display-sync.md)。
