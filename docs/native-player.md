# 原音质观看：IINA、原始外挂字幕与弹幕（0.11）

在观看页点击“原音质观看（IINA）”。首次需要通过系统对话框选择与影片对应的中文外挂；工作台会建议同目录中唯一匹配的中文字幕，仍需用户授权。没有可用外挂时不会启动无字幕播放。首次完成后自动恢复字幕与播放方式偏好；打开 IINA 后恢复进度并保持暂停，请在 IINA 点击播放。

影片、外挂、弹幕分别显示就绪状态。原始 ASS 作为 IINA 主字幕轨，原样保留样式、定位、换行；弹幕由随项目提供的 Lua OSD 绘制，不占字幕轨。默认避开底部 25% 对白区域。Ctrl+Shift+D 独立切换弹幕；网页中的开关、字号、不透明度、估算筛选和弹幕／字幕各自 ±5 秒偏移也可控制原生会话。原生播放时不能卸载必需的外挂，但可替换文件；关闭字幕会明确显示需要处理，不会继续标记三路全部就绪。

原音质路径不重编码音频或视频。为避免 macOS 的“最近使用”属性让原片缓存误失效，IINA 通过仅限本机、每次会话独享的 HTTP Range 接口读取原始 MKV 字节；这不是转码或媒体副本。该读取进程在工作台退出后继续服务于对应 IINA 实例，播放器结束后停止。不会操作用户其他 IINA 窗口或写入 IINA 全局配置；本次进程关闭缩略图预览和自动连续选集。

本片源音轨为 DTS-HD MA 5.1／48 kHz。页面区分源音轨与播放器输出；普通耳机或电脑扬声器通常输出双声道，不会宣称已经实现真实 5.1。应用没有新增有损转码，不代表系统混音、蓝牙、DAC 及扬声器整条链路已经通过 bit-perfect 验收。

“返回网页播放”会保存位置，关闭本工具创建的原生会话，再在网页恢复且暂停。网页兼容播放可能转换为 AAC，并显示音质提醒。关闭网页或正常退出工作台不会强行关闭 IINA；工作台再次启动会尝试重连自己仍存活的会话。原生会话持有进度写入权，旧网页不能用停留位置覆盖新进度。

只保存少量弹幕／配置文件，不生成完整视频或音频文件，不重新下载或对齐。首轮按现有行为支持 SRT、VTT、ASS、SSA；IINA 使用所选原文件。外挂文件版本不同可能产生时间偏差，文件名及成功加载均不证明对白已经同步，不自动对其套用 B站时间映射。

## 接口

所有接口沿用本机认证与文件 ID，拒绝任意路径及播放器命令。

- `GET /api/playback/native/capabilities`：安装情况、字幕要求及播放方式。
- `GET /api/playback/native/items/{item_id}`：已有会话及同目录唯一中文字幕文件名建议；建议不会自动授权读取字幕内容。
- `POST /api/playback/native/sessions`：`item_id`、可选 `subtitle_id`，未传时使用已保存的字幕。
- `GET /api/playback/native/sessions/{id}`：三路状态、字幕名称、数量、源音轨、播放器输出、观看状态。
- `DELETE /api/playback/native/sessions/{id}`：结束本工具的会话并交回进度。
- 观看状态增加 `preferred_engine=web|iina`；现有设置及偏移继续使用原接口。原生会话活跃期间，网页位置写入会被忽略，其他合法设置仍可同步。

会话与读取端口由私有目录及随机能力值保护，Unix socket 仅允许当前用户访问。它们不向网页暴露任意 JSON IPC 控制能力。启动失败、字体替代、原生脚本、设备链路等诊断不会被当作实际听感或真实字幕同步验收。

## 弹幕流畅度（0.11.1）

弹幕使用独立的平滑动画时钟，并以影片时间校准。按显示刷新率调度（默认 60、最高 120 次/秒），暂停、缓冲和关闭弹幕时停止动画；该设置不改变影片帧率、音频同步或外挂 ASS 轨。文字与样式缓存复用。字号仍在观看页的“弹幕设置 → 字号”调整，原有选择保留；不自动放大或缩小。

实测对比及验收范围见 [弹幕流畅度验收](native-danmaku-smoothness.md)。

## 显示同步修复（0.11.2）

IINA 会话使用不重采样音频的 `display-vdrop` 显示同步，让 OSD 绘制不再受 24 fps 片源直接限制。保活会话重连时也会配置。网页会显示已配置／实际启用状态，不能启用时明确提示；不会以设置值宣称实际弹幕帧率。详见 [本片真实绘制对照](native-display-sync.md)。
