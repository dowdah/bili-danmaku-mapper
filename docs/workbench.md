# 本地弹幕对齐工作台（0.11.2）

## 日常使用

1. 在 Finder 中双击项目根目录的 `启动.command`。脚本自动使用项目 `.venv`，打开浏览器；再次双击会回到正在运行的同一个服务。
2. 粘贴 B站视频或番剧链接，点击「识别链接」。BV/AV、多P `?p=`、普通合集、番剧 ep/ss/md 和 b23.tv 分享链接均有入口。链接指定的分P或剧集会标记为当前项。
3. 点击「选择影片」或「选择影片目录」，在 macOS 系统对话框选择本地版本。目录首版读取直属视频文件，不递归读取整个磁盘。
4. 单影片配对明确时点击「准备弹幕」即可；多集或有歧义时检查配对表，可调整集号偏移或逐行改选。只有已勾选且配对完整的内容才能开始；重复集号、特典和没有明确集号的文件需要你确认。
5. 单集整片对齐完成后，点击「观看成品」在「观看」页加载影片与弹幕，其余集数继续下载与对齐。新结果不会自动切页、播放或替换当前观看版本。人工复核在高级功能中，进入前提示可能剧透。

默认使用严格模式、音画共同定位及最高 720P H.264 参考视频。高级设置可改用宽松模式、较低参考清晰度和指定本地音轨。音轨选择在网页上从 1 显示；内部配置仍是从 0 开始的音频流序号。

需要会员、地域访问权限或登录时，点击「登录 B站」，用手机 B站扫码并确认。验证码、安全验证由你在 B站完成。Cookie 写入 `BASE_DIR/cookies.json`，以仅当前用户可读写的权限保存，兼容 CLI 的登录文件；启动时验证，并在使用期间定期检查、刷新。二维码过期可以直接刷新。

对齐始终直接读取用户选择的原片，MKV、HEVC 或其他容器/编码不会阻止创建任务，也不要求先生成副本。高级设置中的音轨用于音画对齐，序号对每集分别校验。网页观看优先直放，自动检测到音频不兼容时启用按需分段传输，保留视频、只将音频转换为 AAC 双声道，并提示音质变化；不支持的情况仍保留手动修复入口。普通观影流程不转码视频或生成整片副本。使用 IINA 可保留原音轨及原始 ASS 样式。详见 [按需播放](viewing-upgrade.md) 与 [原音质观看](native-player.md)。

## 成品观看

顶部「观看」支持已完成成品和独立手动导入，无需创建任务或检查 B站登录。网页播放切回「准备影片」时自动暂停，后台任务继续运行；每部影片独立保存观看位置、音量、倍速及弹幕设置。网页观看采用本地 NPlayer，可挂载 SRT/VTT/ASS/SSA 对白字幕，并分别保存字幕和弹幕 -5～+5 秒偏移。网页将 ASS/SSA 转为文本显示，复杂样式请用 IINA。详见 [成品播放器](finished-player.md)。

## 任务与复核

关闭网页不会停止任务。双击启动脚本可以重新打开当前任务列表。网页的「暂停后续」允许当前阶段完成，暂停下一次下载和计算；「继续后续」恢复派发。单集可以停止、重试，失败不会阻断其他集数。

点击「停止并退出」会保存阶段状态，停止本服务拥有的下载、计算及文件选择助手，释放端口。没有开机服务。下次启动保留已完成结果，从中断阶段恢复。首版不承诺逐字节下载续传；下载失败会重做该阶段，但已验证参考视频可重用。

高级复核工具提供双视频对照、同步跳转、待复核弹幕导航和人工锚点。取消同步，分别定位画面，记录锚点，再点击「保存锚点并重新对齐」。工作台中「修改配对」可以选择新的本地目标。两者都创建新任务版本，通过 `parent_id` 关联旧版本，不覆盖已有结果。日常观看不要求人工复核；普通界面不展示未来弹幕、影片缩略图或剧情截图。

「弹幕已准备」表示对齐流程完成，不表示每条弹幕准确，也不保证浏览器已能解码。高级功能分别展示可靠、估算及未映射比例，人工复核不是播放条件。默认严格模式不显示不确定结果，新条目隐藏估算弹幕。完全重复的剧情、不同配音、静音和重度遮挡仍可能没有唯一对应位置。可信度是规则评分，不是正确概率。

## 首次启动

需要 Python 3.11+ 及 FFmpeg/FFprobe。缺少 Python 时，启动脚本显示系统安装指引；项目依赖不全时，标准库启动页允许确认安装到项目 `.venv`，无需先安装 FastAPI 才能看到引导。FFmpeg 缺失时显示官方下载页和图形步骤。也可把解压后的 `ffmpeg`、`ffprobe` 放到项目 `tools/ffmpeg/bin/`，无需修改全局 PATH；引导页会重新检测。首版不捆绑 Python、FFmpeg，不修改全局 Python，也不要求 Node。

在终端启动的等价入口为 `python3 launcher.py`。手动安装使用 `python3.11 -m venv .venv` 和 `.venv/bin/python -m pip install -r requirements.txt`。安装需要网络；安装失败会显示重试提示。macOS 下载的代码可能触发系统对脚本的首次打开确认；这是系统行为，项目不绕过系统安全提示。

## 存储和接口

工作台状态在 `data/workbench/state.sqlite3`。每个任务在 `data/workbench/jobs/<任务ID>/` 独立保存原始弹幕、分段获取记录、映射弹幕、待复核文件及报告。旧版播放准备文件保存在 `data/workbench/playback/<准备ID>/`，仍可复用；当前按需分段缓存位于 `data/workbench/segments-v1/`，有 1 GiB 总上限。参考视频缓存位于 `data/workbench/sources/`，使用来源 ID、清晰度与内容摘要验证；特征缓存遵循既有 `AlignConfig` 配置。配置优先级仍为进程环境变量、`.env`、默认值，命令行核心参数继续优先。工作台的每任务选项覆盖该任务的模式、清晰度和音轨。

服务只绑定 `127.0.0.1` 的空闲端口，通过每次启动的会话凭据建立 HttpOnly、SameSite Cookie。启动地址片段在使用后从地址栏清除；不同端口的会话分开。接口校验 Host、Origin，不接受任意文件路径；文件选择后仅通过随机文件 ID 和任务 ID 读取。媒体使用支持 HTTP Range 的文件响应。界面资源全部本地提供，不使用 CDN。

接口职责如下：

| 接口 | 作用 |
|---|---|
| `POST /api/resolve` | 将链接转换为稳定来源列表，保留指定分P |
| `GET /api/auth`、`POST/GET /api/auth/qr` | 登录状态、二维码生成及轮询 |
| `POST /api/pick`、`POST /api/pairs` | 原生文件授权及配对建议 |
| `POST /api/jobs`、`GET /api/jobs/{id}` | 确认配对创建任务及读取状态 |
| `POST /api/jobs/{id}/stop`、`retry` | 单集控制 |
| `POST /api/pipeline/pause`、`resume` | 暂停或恢复派发 |
| `POST /api/revise/{id}` | 人工锚点或目标修正，创建新版本 |
| `GET /api/events` | SSE 阶段事件与重连快照 |
| `GET /api/files/{id}` | 已授权影片或任务产物，支持 Range |
| `POST /api/exit` | 保存阶段并停止本地服务 |

一个异步下载槽位与一个独立计算进程槽位并行，最多两集已准备完毕的任务等待计算。参考视频和当前可访问分段弹幕完整准备后才启动该集计算。能测量的进度显示接收字节、处理帧或音频窗口；其他阶段只显示状态和耗时。任务完成、播放副本及最终输出均采用阶段检查和原子发布。播放准备另有一个独立进程槽位，通过轮询显示阶段与耗时，不占用对齐队列，也不重算弹幕。工作进程监测服务父进程，服务异常退出后也会终止本计算组。

CLI 与独立 `player.html` 继续保留。工作台首版不提供直播、收藏夹、互动视频、镜头调序、局域网共享或云端部署。分段弹幕是获取当时可访问的内容，不能理解为全部历史弹幕。

工作台基线验收见 [workbench-acceptance.md](workbench-acceptance.md)，新增观看功能及人工验收边界见 [finished-player-acceptance.md](finished-player-acceptance.md)。
